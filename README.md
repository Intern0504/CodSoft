# CodSoft Python Internship – July 2025

This repository contains the tasks I completed as part of my Python Programming Internship at **CodSoft**. Each task demonstrates practical programming skills using Python.
 Task 1: Password Generator
A Python script that generates strong and random passwords.
 Features:
- User inputs desired password length
- Password includes uppercase, lowercase, digits, and symbols
- Easy to use and beginner-friendly

---

 Task 2: Calculator
 A basic calculator that performs simple arithmetic operations.
 Features:
- Supports addition, subtraction, multiplication, and division and power(exponentiation)
- Takes user input for numbers and operations
- Displays result in the terminal
- asks the user if they want to use it again or not

Task 3: Rock-Paper-Scissors Game
A fun terminal-based game where the user plays Rock-Paper-Scissors against the computer.
Features:
- Takes user input for rock, paper, or scissors
- Random move generation for computer
- Displays the result (Win/Lose/tie)
- Option to play multiple rounds
